## Rhythmic Meditation v1.0.0 — Internal Stable Android Release

Direct Android APK for internal use; this public repository makes release assets
publicly downloadable. No Play Store binary or submission is included.
Meditation provides inward/restorative evidence; Routine remains the policy and
native-enforcement authority.

### Highlights

- Morning Meditation, Routine-bound Cooldown Restorative Meditation, Evening
  practice, and standalone practice.
- Screen-off qualification, persisted checkpoints, conservative process-death
  recovery, and a scoped active-session foreground service.
- Routine recovery/status IPC with same-signer caller verification.
- Local session history and Insights; local-first/no-cloud design.
- Meditation completion never shortens a Routine cooldown.
