## Release summary

Meditation is the inward/restorative evidence authority. Rhythmic Routine retains
cooldown, restorative-choice, and device-enforcement policy.

- Morning Meditation, Routine-bound Cooldown Restorative Meditation, Evening
  Wind-Down, and standalone practice.
- Session history and local Insights; local-first storage with no cloud service.
- Screen-off qualification based on monotonic time and conservative persisted
  checkpoints.
- Process-death-safe recovery and a narrowly scoped active-session foreground
  service; timing remains in the runtime, not the service.
- Routine recovery/status IPC and read-only Routine/Reader Insights inputs with
  protocol/date validation and signature/caller verification.
- Meditation evidence cannot shorten cooldowns or create policy/gates locally.

## Validation boundary

Primary ecosystem physical qualification was on the Xiaomi Redmi Note 13 Pro+ 5G,
Android 16 / API 36. Full CD3/CD4 physical acceptance, extended reboot/time
change permutations, broader OEM work, long-horizon battery observation,
multi-day Insights qualification, and repeatable shared-signer instrumentation
remain tracked as open post-release QA debt in Routine issues #8–#11.

This is a direct/private internal Android release, not a Play Store release. It
does not claim exhaustive OEM certification or medical/addiction-treatment use.
